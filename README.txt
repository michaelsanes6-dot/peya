PeyaTurnos 1.0
Detector de turnos para PeYa Rider.

Esta versión NO reserva turnos automáticamente.
1. Compilar el proyecto con Gradle/Android Studio.
2. Instalar la APK.
3. Abrir PeyaTurnos.
4. Activar el servicio en Ajustes > Accesibilidad.
5. Abrir PeYa Rider y dejar que PeyaTurnos detecte texto de turnos.

Nota: la detección depende de cómo PeYa Rider muestre el contenido y puede requerir ajustar las palabras detectadas.
